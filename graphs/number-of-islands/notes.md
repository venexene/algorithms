# Number of Islands

## Решение

### DFS с подсчётом компонент — O(m × n), O(m × n)
Проходим по матрице. Когда встречаем `'1'` — увеличиваем счётчик островов и запускаем «затопление» (flood fill). Затопление рекурсивно заменяет все связанные `'1'` на `'0'` — остров «удаляется» из матрицы, больше не будет посчитан повторно.

Тот же паттерн что в Flood Fill, только добавлен внешний счётчик.

## Что важно запомнить
- Flood fill для подсчёта компонент связности — стандартный шаблон для задач на матрицах
- Мутация матрицы (замена на `'0'`) заменяет visited — не нужен отдельный map
- Порядок: сначала `res++`, потом `flood()`. Иначе затопленный остров не посчитается
