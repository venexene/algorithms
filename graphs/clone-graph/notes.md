# Clone Graph

## Решение

### DFS + visited map (orig → clone) — O(n), O(n)
Рекурсивно клонируем каждый узел. `visited: map[*Node]*Node` связывает оригинал с его копией. Для каждого соседа: если ещё не клонирован — рекурсивно клонируем и добавляем результат. Если уже клонирован — добавляем существующую копию из visited.

## Что важно запомнить
- `visited` хранит ОРИГИНАЛ → КЛОН, не `int` (Val). Разные узлы могут иметь одинаковое значение.
- `dfs` возвращает клон — не нужен внешний `res`
- Для уже посещённого соседа — добавляем `visited[n]` (клон), не пропускаем и не добавляем оригинал
- Каждый узел создаётся ровно один раз и сохраняется в visited

## Что пошло не так
1. `visited[int]` вместо `visited[*Node]` — коллизия значений
2. Один общий `res` для всех узлов вместо отдельного клона на каждый
3. Добавлял оригинального соседа в Neighbors клона вместо его копии
