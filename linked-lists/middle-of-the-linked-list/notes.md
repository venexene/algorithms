# Middle of the Linked List

## Решение

### Fast & slow pointers — O(n), O(1)
Два указателя: `slow` (шаг 1), `fast` (шаг 2). Когда `fast` доходит до конца, `slow` указывает на середину. Для чётной длины возвращает второй из двух средних.

## Что важно запомнить
- Условие цикла: `fast != nil && fast.Next != nil`. Без проверки `fast.Next` — паника на `fast.Next.Next`.
- Для чётной длины `fast` становится nil → `slow` на втором среднем. Для нечётной `fast.Next` == nil → `slow` ровно посередине.
- Тот же паттерн что в Linked List Cycle, только условие выхода другое.
