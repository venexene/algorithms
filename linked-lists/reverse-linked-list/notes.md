# Reverse Linked List

## Решение

### Итеративный — O(n), O(1)
Три указателя: `prev`, `node`, `next`. На каждом шаге: сохраняем `next`, разворачиваем `node.Next → prev`, сдвигаем `prev` и `node` вперёд. Возвращаем `prev` — после цикла `node == nil`, `prev` это новая голова.

### Рекурсивный — O(n), O(n)
Tail recursion: передаём `node` и `prev`. Base case: `node == nil` → `prev`. На каждом шаге: сохраняем `next`, разворачиваем ссылку, рекурсивно вызываем с `(next, node)`.

## Что важно запомнить
- `var prev *ListNode = nil` — начальный prev. Можно просто `nil`.
- После цикла возвращать `prev`, не `node`. `node` всегда `nil`.
- `head.Next = nil` нужно только если не используешь `prev = nil` подход.
- Крайние случаи `nil` и один элемент обрабатываются циклом автоматически.

## Что пошло не так
1. Пытался обрабатывать `head == nil` и `head.Next == nil` отдельно — цикл с `prev = nil` покрывает оба
2. Возвращал `node` вместо `prev`
