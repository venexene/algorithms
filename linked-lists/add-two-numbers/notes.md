# Add Two Numbers

## Решение

### Поразрядное сложение — O(max(n, m)), O(max(n, m))
Идём по двум спискам одновременно. Складываем значения + перенос из предыдущего разряда. `sum % 10` — текущий разряд, `sum / 10` — перенос. Создаём узел с текущим разрядом, цепляем к tail. Условие `pred != 0` в цикле обрабатывает последний перенос без отдельного if.

## Что важно запомнить
- Условие цикла: `l1 != nil || l2 != nil || pred != 0` — последний перенос создаст дополнительный узел
- `pred = sum / 10` — целочисленное деление, для суммы до 19 даёт 0 или 1
- Dummy + tail паттерн опять: `tail.Next = &ListNode{}`, `tail = tail.Next`, `return dummy.Next`
