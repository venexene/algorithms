# Linked List Cycle

## Решение

### 1. HashSet — O(n), O(n)
Храним пройденные узлы в мапе. Если встретили повторно — цикл.

### 2. Floyd's Cycle Detection (tortoise and hare) — O(n), O(1)
Два указателя: `slow` (шаг 1) и `fast` (шаг 2). Если цикла нет — `fast` дойдёт до nil. Если цикл есть — `fast` догонит `slow` (разница скоростей = 1, встреча гарантирована).

## Что важно запомнить
- Проверка `fast == nil` между шагами — при чётной длине без цикла `fast.Next.Next` паникует
- `fast` двигается на 2, `slow` на 1.
- Floyd — стандарт для задач на циклы. Используется также в Find Duplicate Number.
