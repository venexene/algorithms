# Merge Two Sorted Lists

## Решение

### Dummy node + tail pointer — O(n + m), O(1)
Dummy узел в начале, `tail` всегда указывает на последний узел результата. Сравниваем головы `list1` и `list2`, цепляем меньшую к `tail.Next`, сдвигаем `tail` и соответствующий список. В конце цепляем остаток непустого списка. Возвращаем `dummy.Next`.

## Что важно запомнить
- Dummy node паттерн: `dummy := &ListNode{}`, `tail := dummy`, `return dummy.Next`. Убирает особый случай для первого элемента.
- `tail = tail.Next` — сдвиг хвоста, не путать с продвижением по исходным спискам.
- После цикла ровно один список не пуст — цепляем его целиком.
