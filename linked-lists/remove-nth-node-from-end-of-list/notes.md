# Remove Nth Node From End of List

## Решение

### 1. Счётчик + три указателя — O(n), O(1)
Проходим список один раз. Счётчик `c` отслеживает позицию. Когда `c == n` — запускаем `p2` с головы. `p1` идёт до конца, `p2` отстаёт на n шагов, `prev` хранит узел перед `p2`. В конце удаляем `p2` через `prev.Next = p2.Next`.

### 2. Dummy node + fast/slow — O(n), O(1)
Dummy перед head. `fast` убегает на n+1 шагов. `slow` стартует с dummy. Оба идут пока fast не nil. `slow` оказывается перед удаляемым узлом. `slow.Next = slow.Next.Next`. Возвращаем `dummy.Next`.

## Почему n+1, а не n
`slow` должен указывать на узел ПЕРЕД удаляемым, чтобы сделать `slow.Next = slow.Next.Next`. Отрыв в n+1 даёт ровно это.

## Что важно запомнить
- Dummy node обрабатывает случай удаления головы без отдельного if
- Отрыв fast на n+1, не n — ключевой off-by-one для удаления
