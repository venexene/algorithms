# Intersection of Two Linked Lists

## Решение

### 1. HashSet — O(n + m), O(n)
Проходим список A, складываем узлы в сет. Проходим список B — первый узел который уже в сете и есть пересечение.

### 2. Two pointers (перепрыгивание) — O(n + m), O(1)
Два указателя `p1` и `p2`. Каждый идёт по своему списку. Когда достигает конца — перепрыгивает на голову другого списка. Если пересечение есть — встретятся на нём. Если нет — оба дойдут до nil одновременно.

## Почему это работает
Указатели проходят одинаковое суммарное расстояние: `len(A) + len(B)`. К моменту встречи оба прошли ровно столько узлов сколько нужно чтобы синхронизироваться.

```
A: a1 → a2 → c1 → c2 → c3
B: b1 → b2 → b3 → c1 → c2 → c3

p1: a1, a2, c1, c2, c3, b1, b2, b3, c1 ← встреча
p2: b1, b2, b3, c1, c2, c3, a1, a2, c1 ← встреча
```

## Что важно запомнить
- Условие цикла: `p1 != p2`. Когда оба nil — равны, выход. Когда встретились на узле — равны, выход.
- Перепрыгивание ровно один раз: `if p1 == nil { p1 = headB }`.
- Паттерн «уравнивание расстояния» — элегантная альтернатива сету без доп. памяти.
