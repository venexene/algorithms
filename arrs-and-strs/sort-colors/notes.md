# Sort Colors

## Решение

### Dutch National Flag (один проход, in-place) — O(n), O(1)

Три указателя: `low` (граница нулей), `cur` (текущий), `high` (граница двоек):

- `0` → свап с `low`, затем `low++` и `cur++`;
- `1` → просто `cur++`;
- `2` → свап с `high`, затем `high--` (без `cur++`).

### Альтернатива: подсчёт (counting sort) — O(n), O(1) доп. памяти

Два прохода:

1. посчитать количество `0`, `1`, `2`;
2. перезаписать массив: сначала `count0` нулей, затем `count1` единиц, потом `count2` двоек.

Проще для понимания, но два прохода (по времени те же O(n)).

## Что важно запомнить

- **Dutch National Flag** — эталонный in-place способ отсортировать три значения за один проход.
- **В case `2` не инкрементируем `cur`** — после свапа с `high` на позиции `cur` стоит необработанный элемент.
- **В case `0` инкрементируем `cur`** — слева гарантированно уже `0` или `1`.
- **Условие цикла** `cur <= high`, а не `cur < len(nums)`.
- **Альтернатива с подсчётом** — «посчитал → перезаписал», два прохода, константная доп. память (три счётчика).
