# Add Binary

## Решение

### Поразрядное сложение с конца — O(max(n, m)), O(max(n, m))

Идём с конца обеих строк, складываем биты и перенос `prev`:

- `ba = a[i] - '0'`, `bb = b[j] - '0'` (или `0`, если строка закончилась);
- `res = ba + bb + prev` — принимает значения `0..3`;
- текущий бит = `res % 2`, перенос = `res / 2` (здесь выражен как `res > 1`).

Результат пишем в буфер в обратном порядке, в конце добавляем финальный перенос, затем разворачиваем через `strings.Builder`.

## Что важно запомнить

- **Сумма двух битов + перенос** даёт `res ∈ {0,1,2,3}`: бит = `res % 2`, перенос = `res / 2`.
- **Идём с конца** (младший разряд), как в сложении столбиком.
- **Разная длина строк** — недостающий разряд считаем нулём (`i >= 0` / `j >= 0`).
- **Финальный перенос** — если `prev != 0`, добавить его перед разворотом.
- **Буфер в обратном порядке + разворот** через `strings.Builder` — эффективно и наглядно.
- `a[i] - '0'` — перевод символа цифры в число.
