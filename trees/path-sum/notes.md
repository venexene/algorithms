# Path Sum

## Решение

### DFS — O(n), O(h)
Рекурсивно спускаемся, вычитая `node.Val` из `targetSum`. Если дошли до листа (`Left == nil && Right == nil`) и `targetSum == 0` — путь найден. Иначе продолжаем в левое и правое поддерево через `||`.

## Что важно запомнить
- Проверка именно листа: `Left == nil && Right == nil`, не просто `root == nil`. Иначе сработает на неполном пути.
- `||` между рекурсивными вызовами — short-circuit, выходит рано при первом true.
- Паттерн «вычитание на ходу» чище чем передача накопленной суммы отдельным параметром.
