# Lowest Common Ancestor of a Binary Tree

## Решение

### Рекурсивный DFS — O(n), O(h)

`lowestCommonAncestor(root, p, q)`:

- база: `root == nil || root == p || root == q` → вернуть `root`;
- рекурсивно ищем в левом и правом поддеревьях;
- если оба результата не `nil` → `p` и `q` в разных поддеревьях, значит `root` — LCA;
- иначе вернуть непустую ветку (или `nil`).

Функция возвращает **сам узел**, а не булев признак: найденный `p`/`q` «всплывает» наверх как сигнал, что цель найдена.

## Что важно запомнить

- **Не нужен отдельный `bool`** — возвращаемый узел сам несёт смысл: `nil` = не нашли, не-`nil` = нашли `p`/`q`/LCA.
- **`root == p || root == q`** — когда цель найдена, возвращаем её наверх.
- **`left != nil && right != nil`** — цели в разных поддеревьях, текущий `root` и есть LCA.
- Работает при гарантии, что `p` и `q` есть в дереве (условие LeetCode). Без гарантии нужна дополнительная проверка присутствия.
