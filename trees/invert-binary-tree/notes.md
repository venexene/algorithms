# Invert Binary Tree

## Решение

### DFS (рекурсия) — O(n), O(h)
На каждом узле меняем Left и Right местами. Рекурсивно вызываем для обоих поддеревьев. Возвращаем корень.

## Что важно запомнить
- Swap делается до рекурсии, не после. Порядок не критичен для результата, но логичен: обработал узел → ушёл в детей.
- После swap'а `root.Left` — это бывший правый потомок. Рекурсия идёт уже по новым ссылкам.
- Самая простая задача на деревья — классика для разминки на собесе.
