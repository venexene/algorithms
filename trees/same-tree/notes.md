# Same Tree

## Решение

### DFS (рекурсия) — O(n), O(h)
Сравниваем два дерева. Base cases: оба nil → true, один nil → false. Затем: значения равны И левые поддеревья равны И правые поддеревья равны.

## Что важно запомнить
- Порядок проверок: сначала оба nil, потом одно nil, потом значения. Иначе panic на nil.
- Классический рекурсивный паттерн для деревьев: обработал узел → рекурсия влево → рекурсия вправо.
- `&&` между рекурсивными вызовами — short-circuit evaluation, выходит рано при первом же false.
