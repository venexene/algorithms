# Lowest Common Ancestor of a Binary Search Tree

## Решение

### Использование свойств BST — O(h), O(1)
Если `p` и `q` по разные стороны от root (один ≤ root, другой ≥ root) — root и есть LCA. Если оба меньше — идём налево. Если оба больше — направо.

## Почему это работает именно для BST
В обычном дереве LCA требует полного обхода (оба поддерева, поиск p и q). BST даёт shortcut: свойство Left < root < Right позволяет определить где находятся p и q без обхода — просто сравнивая значения.

## Что важно запомнить
- **`<=`, не `<`.** Когда `p == root` или `q == root` — этот узел и есть LCA. Строгое `<` даст nil.
- Условие «по разные стороны»: `p <= root <= q || q <= root <= p`. Порядок p и q неизвестен — нужны обе комбинации.
- O(h), где h — высота. В сбалансированном BST это O(log n).
- Только для BST. Для обычного дерева — другой алгоритм (рекурсивный обход).

## Что пошло не так
1. Пытался решать без использования свойств BST — общий DFS
2. `<` вместо `<=` — паника на случае когда p или q равен root
