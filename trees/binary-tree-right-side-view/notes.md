# Binary Tree Right Side View

## Решение

### DFS, right-first + отслеживание глубины — O(n), O(h)
Идём справа налево. Если текущая глубина больше максимальной встреченной — узел первый на этом уровне с правой стороны, добавляем в результат. Затем рекурсия: сначала Right, потом Left.

## Что важно запомнить
- Порядок обхода: сначала Right, потом Left. Left-first даст левую сторону.
- Условие `depth > max` — узел виден справа, добавляем.
- Альтернатива: BFS по уровням, брать последний элемент каждого уровня. Менее элегантно, но тоже работает.
