# Diameter of Binary Tree

## Решение

### DFS снизу вверх (пост-обход) — O(n), O(h)

Диаметр — длина самого длинного пути между любыми двумя узлами, измеряется в рёбрах. Ключевой инсайт: любой такой путь либо проходит через некоторый узел (тогда это сумма высот его левого и правого поддеревьев), либо целиком лежит в одном поддереве (тогда он уже учтён на более низком уровне).

`dfs(node)` возвращает **высоту поддерева в узлах**:
- `nil` → `0`
- `left := dfs(node.Left)`, `right := dfs(node.Right)`
- кандидат диаметра через узел: `left + right` (это рёбра)
- возврат высоты: `max(left, right) + 1`

Сам диаметр копим во внешней переменной через указатель и обновляем на каждом узле.

## Что важно запомнить

- **Диаметр = максимум `left + right` по всем узлам** — сумма высот двух поддеревьев даёт число рёбер пути через узел.
- **`dfs` возвращает высоту, а не диаметр.** Это разные величины: высота — для родителя, диаметр — накопленный глобальный максимум.
- **Высота в узлах, диаметр в рёбрах.** `left + right` равно рёбрам именно потому, что высота считается в узлах (для листа `left=1, right=1` → путь из двух рёбер).
- **Пост-обход обязателен** — сначала обрабатываем детей, потом узел.
- **Накопление максимума через указатель** (`*diameter`) — стандартный приём, когда функция должна вернуть одно, а обновить другое.
