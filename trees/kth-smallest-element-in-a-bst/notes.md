# Kth Smallest Element in a BST

## Решение

### In-order обход с возвратом узла — O(k), O(h)

In-order обход BST даёт значения по возрастанию. Рекурсивная функция возвращает найденный узел:

- `nil` → вернуть `nil`;
- обойти левое поддерево, если вернулся узел — это ответ;
- `k -= 1` (посетили текущий узел); если `k == 0` — текущий узел и есть ответ;
- иначе обойти правое поддерево.

## Другие варианты

### 1. Рекурсивный со счётчиком (канон)

Заводим `count` и `res` в замыкании, без возврата узла.

Читается проще, но без раннего выхода обойдёт всё дерево. Для прерывания добавляют `if count >= k { return }` в начале.

### 2. Итеративный со стеком (без рекурсии)

In-order через явный стек, O(h) памяти, прерывается ровно на k-м узле.

## Что важно запомнить

- **In-order обход BST = отсортированная последовательность** — ключевое свойство для k-го наименьшего/наибольшего.
- **Рекурсивный со счётчиком** — самый читаемый канон; **итеративный со стеком** — когда нужен точный ранний выход или нельзя рекурсию.
- **`k` мутируется** (декремент на каждом посещённом узле) — удобный приём через замыкание.
- Сложность: O(k) узлов фактически, O(h) памяти.

## Что пошло не так

- Первая версия возвращала `*TreeNode` через `left`/`right` с проверкой `if left != nil` — работала, но запутанно. Упрощено: сначала проверяем `left`, потом `k -= 1`.
