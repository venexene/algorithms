# Binary Tree Level Order Traversal

## Решение

### 1. Две очереди — O(n), O(n)
Основная очередь и буферная. Обрабатываем основную — дети кладём в буферную. Когда основная опустела — меняем их местами. Уровень завершён.

### 2. Одна очередь + levelSize — O(n), O(n)
В начале каждого уровня запоминаем `levelSize = len(queue)`. Обрабатываем ровно `levelSize` элементов — это все узлы текущего уровня. Дети добавляются в конец очереди, но цикл останавливается раньше. Без буферной очереди, меньше кода.

## Что важно запомнить
- BFS на деревьях = очередь. DFS = рекурсия или стек.
- `levelSize = len(queue)` — ключевой трюк для разделения уровней без второй очереди.
- `res = append(res, []int{})` в начале уровня, потом `res[len(res)-1] = append(res[len(res)-1], node.Val)` — добавляем элементы в последний слайс.
- `queue = queue[1:]` — удаление из головы очереди. Для больших деревьев неоптимально (O(n) сдвиг), но для LeetCode ок.
