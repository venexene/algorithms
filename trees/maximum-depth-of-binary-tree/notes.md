# Maximum Depth of Binary Tree

## Решение

### 1. DFS с передачей глубины — O(n), O(h)
Спускаемся по дереву, передавая текущую глубину в параметре. На каждом узле `depth++`, берём `max` левого и правого поддерева.

### 2. DFS без параметров — O(n), O(h)
Короче: `if root == nil { return 0 }`. Возвращаем `1 + max(левое, правое)`. Глубина поднимается снизу вверх, а не передаётся сверху вниз.

## Что важно запомнить
- Пустое дерево → глубина 0. Лист → глубина 1.
- Рекурсия на деревьях: либо передаёшь состояние вниз (параметром), либо поднимаешь результат вверх (return). Второй вариант почти всегда короче.
