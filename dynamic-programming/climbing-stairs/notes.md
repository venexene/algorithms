# Climbing Stairs

## Инсайт

Это числа Фибоначчи: `f(n) = f(n-1) + f(n-2)`. На ступень `n` можно попасть либо с `n-1` (шаг 1), либо с `n-2` (шаг 2). База: `f(0) = 1` (путь без шагов), `f(1) = 1`.

## Решение

### Две переменные (bottom-up DP) — O(n), O(1)

`a, b = b, a+b` — классическая свёртка Фибоначчи. `a` хранит `f(i)`, `b` хранит `f(i+1)`. После `n` итераций `a` содержит `f(n)`.

Начальные значения: `a=1, b=1` → это `f(0)` и `f(1)`.

## Что важно запомнить

- **DP не всегда требует массива.** Если состояние зависит только от двух предыдущих — достаточно двух переменных
- **Параллельное присваивание Go:** `a, b = b, a+b` — вычисляется одновременно, не нужно временной переменной
- **База f(0)=1:** на LeetCode для n=0 ответ 1 (единственный способ — не делать шагов). Это отличается от математического Fib(0)=0
- **Структура DP-задачи:** определил рекуррентное соотношение → свёл к O(1) памяти
