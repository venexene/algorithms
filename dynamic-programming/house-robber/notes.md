# House Robber

## Инсайт

DP с двумя вариантами на каждом шаге: `dp[i] = max(dp[i-1], nums[i] + dp[i-2])`. Либо пропускаем дом `i` и берём лучшее с `i-1`, либо грабим `i` и добавляем лучшее с `i-2` (соседей грабить нельзя).

## Решение

### In-place DP — O(n), O(1)

Мутируем входной массив. База: `nums[1] = max(nums[0], nums[1])`. Цикл с `i=2`: `nums[i] = max(nums[i-1], nums[i] + nums[i-2])`. Ответ — `nums[n-1]`.

## Что важно запомнить

- **Две опции, не три.** На шаге `i` решение бинарное: грабим или нет. Не нужно сравнивать с `nums[i-3]` — `dp[i-2] ≥ dp[i-3]` всегда, так как dp не убывает
- **`nums[1] = max(nums[0], nums[1])`** — инициализация второго дома до цикла. Без неё формула `nums[i] + nums[i-2]` на `i=2` работала бы некорректно
- **Ответ — последний элемент.** После цикла `nums[n-1]` хранит `dp[n-1]`, т.е. максимум для всего массива. Не нужно брать `max` по нескольким последним
- **In-place DP** — тот же паттерн что в Min Cost Climbing Stairs: мутируем вход, экономим память

## Что пошло не так

1. **Три варианта в max** — сравнивал `nums[i] + nums[i-3]`, `nums[i-1]` и `nums[i] + nums[i-2]`. Третий член избыточен: `dp[i-2]` всегда не хуже `dp[i-3]`, поэтому `nums[i] + nums[i-3]` никогда не выигрывает у `nums[i] + nums[i-2]`
2. **Сложный return** — `max(nums[n-3], max(nums[n-1], nums[n-2]))`. После цикла `nums[n-1]` уже содержит ответ для всего массива
