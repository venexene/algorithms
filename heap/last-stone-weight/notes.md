# Last Stone Weight

## Решение

### Max-heap — O(n log n), O(n)

Кладём все камни в max-heap. Пока камней больше одного:
1. Достаём два самых тяжёлых (`stone1 >= stone2`)
2. Их разность кладём обратно

В конце либо остаётся один камень — его вес, либо ничего — возвращаем 0.

## container/heap для max-heap

Go по умолчанию строит min-heap. Чтобы получить max-heap, достаточно инвертировать `Less`:

```go
func (h IntHeap) Less(i, j int) bool { return h[i] > h[j] }
```

`h[i] > h[j]` — корень становится максимумом. Всё остальное (`Len`, `Swap`, `Push`, `Pop`) не меняется.

## Что важно запомнить

- **Max-heap в Go — это просто перевёрнутый `Less`.** Нет отдельного типа.
- **`heap.Init(&h)` обязателен.** Иначе слайс — это просто слайс, а не куча, и `heap.Pop` вернёт не максимум.
- **Пакетные функции vs методы.** Вызывай `heap.Push(&h, x)` и `heap.Pop(&h)`, а не `h.Push(x)` / `h.Pop()` — пакетные сами чинят кучу (up/down). Твои методы только добавляют/удаляют последний элемент.
