# Partition Equal Subset Sum

## Решение

### DP 0/1 рюкзак по сумме — O(n·target), O(target)

Задача сводится к вопросу: **есть ли подмножество с суммой `total/2`?** Если есть — остальные элементы автоматически дадут вторую половину.

- Если `total` нечётное → `false`.
- `target := total / 2`.
- `dp[s] = true`, если сумму `s` можно набрать из рассмотренных элементов. База: `dp[0] = true` (пустое подмножество).
- Для каждого элемента `x` проходим `s` от `target` вниз до `x`: `dp[s] = dp[s] || dp[s-x]`.
- Ответ — `dp[target]`.

## Что важно запомнить

- **Свести к «набрать сумму»** — половина `target = total/2`; второе множество получается автоматически.
- **Состояние — только сумма**, не индексы: `dp[s]` булево.
- **Проход сверху вниз** (`s` от `target` до `x`) — чтобы элемент брался не более одного раза (0/1 рюкзак). Проход снизу вверх дал бы неограниченный рюкзак (повторное использование).
- **Нечётная `total`** → сразу `false`.
- **Жадность / two pointers не работают** — это выбор подмножества, порядок элементов не важен, нужен псевдополиномиальный DP.

## Что пошло не так

- Пытался решить жадностью с двумя указателями (сортировка + парное вычитание) — неверно: задача про произвольные подмножества.
- Центральный элемент при нечётном размере терялся: `if left == right` недостижим внутри `for left < right`.
- Контрпример: `[1, 2, 3, 4]` — жадность даёт `false`, а правильный ответ `true` (`[1,4]` и `[2,3]`).
