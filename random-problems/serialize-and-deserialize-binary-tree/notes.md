# Serialize and Deserialize Binary Tree

## Решение

### BFS по уровням с маркером nil — O(n), O(n)

**Сериализация:** BFS от корня. Для каждого узла пишем значение, а для отсутствующего ребёнка — `#`. `nil`-дерево → `""`.

**Десериализация:** разбиваем строку по разделителю, первый токен — корень; дальше идём по очереди и восстанавливаем детей по индексу `i`.

**Ключ к nil vs 0:** пустая строка `""` означает `nil`-дерево, а корень со значением `0` сериализуется в `"0"` (через `strconv.Itoa`) — конфликта нет.

## Оптимизация: обрезка хвостовых `#`

В BFS лишние `#` — это только `nil`-дети узлов последнего уровня, они идут в самом конце. Их можно срезать: собрать токены, затем удалить все `#` с конца. Внутренние `#` трогать нельзя — они задают структуру.

Пример: дерево `[1]` → `"1|#|#"` обрезается до `"1"`; при этом `nil`-дерево остаётся `""`, корень `0` — `"0"`.

## Что важно запомнить

- **Формат свободный** — главное, чтобы `deserialize(serialize(root)) == root`; LeetCode не навязывает конкретную строку.
- **Пустая строка = nil-дерево**, непустая — валидное дерево. Значение `0` пишется как `"0"`, поэтому nil и корень-ноль различимы.
- **BFS + маркер `#`** — каждый узел даёт ровно два токена (левый и правый ребёнок).
- **Лишние `#` бывают только в хвосте** — их можно обрезать; внутренние обязательны.
- Для сборки строки используй `strings.Builder` или `strings.Join`.
