# Spiral Matrix

## Решение

### Обход с четырьмя границами — O(m·n), O(1) доп. памяти

Поддерживаем границы `top`, `bottom`, `left`, `right`. Пока `top <= bottom && left <= right`, идём по спирали:

1. вправо по строке `top`: `j` от `left` до `right` → `top++`;
2. вниз по столбцу `right`: `i` от `top` до `bottom` → `right--`;
3. влево по строке `bottom` (только если `top <= bottom`) → `bottom--`;
4. вверх по столбцу `left` (только если `left <= right`) → `left++`.

## Что важно запомнить

- **Четыре границы + четыре прохода**, каждый сдвигает свою границу.
- **Защитные условия для «влево» и «вверх»**:
  - «влево» — только если `top <= bottom` (осталась строка);
  - «вверх» — только если `left <= right` (остался столбец).
  Они спасают от дублей, когда матрица вырождается в одну строку/столбец.
- **Внешнее условие** `top <= bottom && left <= right` — старт «вправо» и «вниз» уже гарантирован, отдельные проверки им не нужны.
- **Используй границы прямо в индексах** (`matrix[top][j]`, `matrix[i][right]`, …) — не заводи «плавающие» `i`/`j`, которые уезжают за пределы.
- Capacity: `len(matrix) * len(matrix[0])`.

## Что пошло не так

- Первая версия с «плавающими» `i`/`j` уезжала за границы (`index out of range`) и теряла остаток при одной строке/столбце.
- Путал условия `top <= bottom` и `left <= right` местами — «влево» и «вверх» срабатывали не там, давали дубли.
