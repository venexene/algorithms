# Generate Parentheses

## Решение

### Backtracking с отсечением невалидных префиксов — O(числа Каталана)

Строим последовательность посимвольно, добавляя `(` или `)`, но обрубаем ветки, которые уже не могут стать валидными.

## Ключевая идея: инварианты валидности

Вместо перебора всех 2^(2n) последовательностей строим только валидные префиксы:

1. **`close > open`** — нельзя закрыть больше, чем открыли. В любой момент число `)` не должно превышать число `(`.
2. **`open > n`** — не больше n открывающих.

Эти два условия гарантируют: любая последовательность длины 2n, дошедшая до базового случая, валидна автоматически. Проверять `close > n` не нужно — оно следует из `close ≤ open ≤ n`.

## Что важно запомнить

- **Классика баланса скобок** — инвариант `open >= close` на любом префиксе.
- **Сложность = число Каталана** C(n) = C(2n, n)/(n+1). Это оптимум — ровно столько валидных последовательностей существует, меньше перебрать нельзя.
- **Отсечение до построения** — мёртвые ветки режутся по мере роста, а не проверкой в конце.
- **Откат строки через срез** — `str[:len-1]` за O(1).
