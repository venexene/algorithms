# Letter Combinations of a Phone Number

## Решение

### Backtracking с наращиванием строки — O(4^n · n)

Каждая цифра (2–9) даёт набор букв. Нужно перебрать все комбинации.

```go
func dfs(digits, str string, ind int) {
    if ind == len(digits) {
        res = append(res, str)
        return
    }
    for _, l := range alphabet[digits[ind]] {
        str += l
        dfs(digits, str, ind+1)
        str = str[:len(str)-1] // откат
    }
}
```

На каждом уровне добавляем одну из букв текущей цифры и идём глубже. Срез строки `str[:len-1]` — O(1), не копирует данные.

## Ключевая идея

Комбинация = путь в дереве, где каждый уровень — выбор одной буквы из набора цифры. Глубина дерева = число цифр.

```
"23" → 2:{a,b,c} × 3:{d,e,f}
ad ae af bd be bf cd ce cf
```

## Что важно запомнить

- **Пустая строка — особый случай.** При `digits == ""` рекурсия сразу добавляет `""` в результат и вернётся `[""]`. LeetCode ожидает `[]`. Нужен ранний выход `if digits == "" { return []string{} }`.
- **Откат строки через срез** — `str = str[:len(str)-1]` работает за O(1), потому что строка в Go — это заголовок на те же байты.
- **`str += l` создаёт новую строку** — для строк ≤ 4 символов ок, в общем случае O(n²). Альтернатива — `strings.Builder`.
- **Map с наборами букв** — можно вынести в package-level, чтобы не строить при каждом вызове.
