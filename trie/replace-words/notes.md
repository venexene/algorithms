# Replace Words

## Решение

### Trie + поиск кратчайшего корня — O(сумма длин слов)

Строим trie из словаря. Для каждого слова предложения ищем в trie кратчайший корень-префикс и заменяем слово на него. Если корня нет — оставляем слово как есть.

`FindRoot(word)` идёт по символам, накапливает префикс в `strings.Builder`, и как только встречает `isEnd` — возвращает накопленное. Так как перебор идёт по возрастанию длины, первый `isEnd` — это и есть **кратчайший** корень.

## Ключевая идея

**Первый `isEnd` = кратчайший корень.** Не нужно сравнивать длины или хранить кандидатов — просто возвращаем при первом же конце слова.

```
dict = ["a", "ab"], word = "abc"

a → isEnd ✅ → возвращаем "a" (не "ab")
```

Если путь оборвался (`node == nil`) — корня нет, возвращаем `""`.

## Что важно запомнить

- **Поиск корня в trie = обычный обход + возврат при `isEnd`.** Никакой сортировки словаря не нужно.
- **`FindRoot` возвращает сам корень, а не bool** — для этой задачи нужен не факт «есть ли», а конкретная строка.
- **Проверка `isEnd` внутри цикла покрывает и точное совпадение слова с корнем** — отдельная проверка после цикла не нужна (мёртвый код).
- **`byte(r)` для lowercase безопасен** — в trie только латиница.
