# Koko Eating Bananas

## Решение

### Бинарный поиск по ответу — O(n log m), O(1)
Ищем минимальную скорость. Диапазон: `[1, max(piles)]`. На каждом шаге считаем часы для скорости `mid`: `∑ ceil(pile / mid)`. Если укладываемся в `h` — пробуем медленнее (`high = mid`). Иначе — быстрее (`low = mid + 1`).

Паттерн Find Minimum: `high = mid` когда mid валиден, `low = mid + 1` когда нет.

## Что важно запомнить
- Ceil division: `(p + speed - 1) / speed`. `3/2 = 1`, но `(3+1)/2 = 2` — правильно.
- `sum/mid` не работает — бананы из разных куч нельзя складывать, каждая куча требует ceil отдельно.
- Паттерн `low < high` + `high = mid` для минимального значения удовлетворяющего условию.

## Что пошло не так
1. Использовал `sum/mid` вместо `∑ ceil(pile/mid)` — не учёл что кучи независимы и нужен ceil
2. Перепутал напраление: делал `low = mid + 1` для валидной скорости — перескакивал ответ
