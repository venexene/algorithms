# Binary Search

## Решение

### Классический бинарный поиск — O(log n), O(1)
`low = 0, high = n-1`. Пока `low <= high`: берём середину, сравниваем с target. Если target больше — идём вправо, иначе — влево. Нашли — вернули индекс. Не нашли — `-1`.

## Что важно запомнить
- `low <= high`, не `low < high`. Одноэлементный массив должен провериться.
- `mid = (high + low) / 2` — для Go безопасно (int произвольной точности), в других языках может переполниться при больших значениях.
- `low = mid + 1`, `high = mid - 1` — не `mid`, иначе бесконечный цикл на неудачном поиске.

## Что пошло не так
1. `low < high` — одноэлементный массив не проверялся, возвращал `-1` даже когда target присутствовал
