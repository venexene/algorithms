# Search Insert Position

## Решение

### Бинарный поиск — O(log n), O(1)
Стандартный бинарный поиск. Если target найден — вернули индекс. Если нет — после выхода из цикла `low` указывает на позицию вставки.

## Что важно запомнить
- После неудачного поиска `low` — позиция вставки. Без дополнительных `if/else` с `mid`.
- `low <= high`, `mid+1`, `mid-1` — классические константы бинарного поиска.
