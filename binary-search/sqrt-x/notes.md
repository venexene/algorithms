# Sqrt(x)

## Решение

### Бинарный поиск по ответу — O(log n), O(1)
Ищем наибольшее целое `ans` такое что `ans² ≤ x`. Бинарный поиск в диапазоне `[0, x]`. Если `mid² > x` — ответ слева. Иначе — `mid` кандидат, ищем правее. В конце `low - 1`.

## Почему `low - 1` и почему без осечек

Инвариант на каждой итерации: `low` — левая граница возможных ответов, `high` — правая. После цикла `low > high` — диапазон схлопнулся.

Ветвление:
- `mid² > x` → ответ точно меньше mid → `high = mid - 1`. Здесь mid не подходит.
- `mid² ≤ x` → mid подходит, но может быть больше → `low = mid + 1`. Здесь mid — валидный кандидат.

В последней итерации когда `low == high`: mid равен этому единственному кандидату. Если `mid² ≤ x` — `low = mid + 1` перескакивает ЗА правильный ответ. Если `mid² > x` — `high = mid - 1`, и `low` остаётся на mid — но mid не подходит.

В обоих случаях после выхода: `low` указывает на ПЕРВОЕ число, которое НЕ подходит (либо из-за `mid+1`, либо потому что mid сам не подошёл). Поэтому правильный ответ — `low - 1`, последнее число которое подошло.

```
x = 8:
step: low=0, high=8, mid=4 → 16>8 → high=3
step: low=0, high=3, mid=1 → 1≤8 → low=2
step: low=2, high=3, mid=2 → 4≤8 → low=3
step: low=3, high=3, mid=3 → 9>8 → high=2
exit: low=3, high=2 → ответ low-1=2 (2²=4≤8, 3²=9>8) ✓
```

Крайний случай `x=0`: `low=0, high=0, mid=0, 0≤0 → low=1`. Ответ `low-1=0`. ✓

## Что важно запомнить
- Бинарный поиск по ответу: ищем не элемент в массиве, а число удовлетворяющее условию
- Паттерн: `if condition(mid) → low = mid+1 else → high = mid-1`, ответ `low-1`
- `low - 1` всегда корректен благодаря инварианту: `low` указывает на первый НЕподходящий
