# Longest Palindrome

## Решение

### Множество символов с нечётным количеством — O(n), O(k)

Идём по строке, храним в `set` символы с нечётным числом вхождений. Встретили символ повторно (он уже в множестве) — образовалась пара: удаляем его и добавляем `+2` к результату. В конце в множестве остаются символы с нечётным счётчиком: если их нет — все разбились на пары; если есть — один такой символ ставим в центр палиндрома (`res + 1`).

## Что важно запомнить

- **Чётность через set, а не через частоты** — пара ловится сразу при повторном вхождении, не нужно хранить `map[char]int`.
- **Один нечётный символ в центре** — если после обработки множество не пусто, добавляем ровно один центр (`res + 1`), остальные нечётные разбиваются на пары без единицы.
- **Краевые случаи** — пустая строка → 0, все парные → `res` без `+1`, все разные → 1.
- **Альтернатива** — частотный массив `[128]int` и `sum += (count/2)*2`, затем `+1` при наличии нечётного счётчика. Для ASCII быстрее, чем `map`.
